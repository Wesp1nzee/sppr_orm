## [Unreleased]

### Добавлено

- Аудит: запись событий `EventBus` в `audit_log_entries`, admin-журнал с
  фильтрами и пагинацией, сводный отчёт по проверке с экспортом DOCX/PDF и
  ретеншен журнала (`scripts/purge_audit_log.py`).
- Генерация процессуальных документов (DOCX/PDF) из результатов проверки.
- База знаний: CRUD API нормативных документов с версионированием и RBAC.
- Проверка законности ОРМ по 14 критериям (движок правил).
- Аутентификация: Redis-сессии + подписанный double-submit CSRF, RBAC.
- Локализация сообщений об ошибках (ru/en).
- Rate limiting на эндпоинтах аутентификации.
- CI (GitHub Actions): lint, typecheck, тесты, сборка Docker-образа.
- Тесты: включена проверка внешних ключей в SQLite; интеграционный прогон всего
  набора на реальном PostgreSQL 18 через `TEST_DATABASE_URL` (`make test-integration`).

### Каркасы (реализация не начата)
